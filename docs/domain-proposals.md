### 추천 구현 순서

> GitHub Trending, Hacker News, arXiv, Dev.to/Hashnode(그리고 YouTube, 뉴스레터)는 이미 구현돼 아래 순서에서 뺐다.

**Phase 1 (1주차)** — 인프라 검증 + 빠른 승리
1. 환율/코인 — stock 스키마 재활용

**Phase 2 (2주차)** — LLM 요약 파이프라인 강화
2. Product Hunt — GraphQL API 경험
3. 패키지 릴리즈 — 개발자 직접 혜택

**Phase 3 (3주차)** — 사용자 확장
4. CVE/보안 — DevOps 타겟
5. HF 모델 — AI 실무자 타겟

**Phase 4 (4주차+)** — 새 영역
6. 취업 공고 / 스포츠 / OTT — 일반 사용자 확장
7. RSS 통합 — 플랫폼화
8. 컨퍼런스/법령 — niche 타겟

## 기술 공통 사항

### 모든 도메인 공통 아키텍처

```
[Source] → [Fetcher] → [Normalizer] → [Dedup] → [LLM Summarize] → [Notify]
```

- **Fetcher**: HTTP/scraping/RSS 통일 인터페이스
- **Normalizer**: 도메인별 스키마 → 공통 스키마 변환
- **Dedup**: URL/제목 기반 중복 제거 (기존 로직 재활용)
- **LLM Summarize**: 3줄 요약 + 키워드 추출
- **Notify**: Telegram / Discord / Email
