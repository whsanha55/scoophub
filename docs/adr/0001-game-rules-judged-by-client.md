# 보드게임 규칙은 클라이언트가 판정하고, 서버는 순서와 시계만 관리한다

체스·장기의 수가 규칙에 맞는지는 프론트엔드의 TypeScript 규칙 코드만 판정한다. 서버는 받은 수를 검증하지 않고, 차례 순서와 기보를 관리하고 다른 사람에게 전달한다. 규칙을 Kotlin과 TypeScript 두 벌로 유지하지 않고, 같은 화면 대국·초대 대국·나중에 붙일 AI가 한 규칙 코드를 함께 쓰기 위해서다. 친구끼리 두는 게임이라 부정행위 위험은 감수한다.

예외로 시계는 서버가 관리한다. 클라이언트 시계는 조작할 수 있으므로, 초대 대국의 남은 시간과 시간패는 서버가 수를 받은 시각으로 판정한다.

## Consequences

- 조작된 클라이언트는 규칙에 어긋나는 수를 보낼 수 있다. 서버에서 이를 막아야 할 정도가 되면, 서버에서도 규칙 판정을 실행하도록 이 결정을 다시 검토한다.
