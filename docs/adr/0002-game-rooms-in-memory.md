# 게임 방은 DB 없이 서버 메모리에만 둔다

방, 대국, 기보, 채팅은 백엔드 메모리에만 둔다. 이용자는 모두 로그인하지 않은 게스트다. 설정과 레몬게임 최고점은 브라우저 localStorage에 둔다. 기보는 대국이 끝나면 남기지 않는다. 기보 다시보기·공유는 서버 저장을 만들 때 다시 설계한다(#302에서 파일 내려받기·URL 해시 공유를 걷어냈다).

## Consequences

- 서버를 재시작하거나 배포하면 진행 중인 초대 대국이 사라진다.
- 방이 인스턴스 하나에 묶이므로 백엔드를 수평 확장할 수 없다. 확장이 필요해지면 Redis 같은 공용 저장소로 옮겨야 한다.
- 로그인이 없어 익명 남용을 막을 수단이 한도뿐이다. 동시 방 수를 게스트 ID당 3개, IP당 20개, 서버 전체 200개로 제한하고, 채팅과 초대코드 입력에도 한도를 둔다.
