# Design System Convention

색상·폰트·간격·모서리 값은 프로젝트에서 정하되 아래 사용 규칙을 따른다.

## 1. 토큰

- 색상은 `background`, `foreground`, `primary`, `muted`, `destructive`처럼 역할이 드러나는 토큰으로 쓴다. 텍스트와 배경의 짝(`primary` / `primary-foreground` 등)을 함께 정의한다.
- 토큰은 CSS 변수 한 곳에서 관리한다. 라이트·다크 모드가 있다면 같은 토큰 이름의 값만 바꾼다.
- 반복되는 글꼴 크기, 간격, 모서리, 그림자도 토큰으로 정의한다. 같은 의미의 값을 화면마다 다르게 지정하지 않는다.
- 브랜드 색상과 폰트의 실제 값은 프로젝트별로 정한다. 이 저장소는 제품의 시각적 정체성을 고정하지 않는다.

## 2. 컴포넌트

- 같은 용도의 컴포넌트를 화면마다 새로 만들지 않는다.
- 공통 컴포넌트는 필요한 `variant`, 크기, `disabled`, 로딩, 오류 상태를 정의한다. 새 variant는 실제 사용처가 생길 때 추가한다.
- 화면은 공통 컴포넌트를 조합한다. 일회성 레이아웃까지 공통 컴포넌트로 추상화하지 않는다.

## 3. 접근성

- 버튼은 `button`, 이동은 `a`, 입력은 연결된 `label` 등 의미에 맞는 HTML 요소를 쓴다.
- 키보드만으로 조작할 수 있어야 하고 포커스 표시를 지우지 않는다.
- 오류는 색상만으로 전달하지 않는다. 입력 항목과 연결된 텍스트로 설명한다.
- 텍스트 대비, 포커스, 클릭 대상 크기는 [WCAG 2.2 AA](https://www.w3.org/TR/WCAG22/)를 기준으로 확인한다.
